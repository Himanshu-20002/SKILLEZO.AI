## 🎥 Recording & Presentation Checklist
1. **Screen Resolution:** 1920x1080 (1080p 60fps) or 2560x1440 (2K).
2. **Theme:** Toggle to matching theme (Dark/Light) according to script stage cues.
3. **Seed Data:** Ensure clean test database with pre-populated demo candidates and jobs.
4. **Microphone:** Clean audio, normalized to -14 LUFS without background noise.
